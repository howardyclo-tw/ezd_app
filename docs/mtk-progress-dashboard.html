🔒 對抗式測試的實際戰果

D1/D2/D3 hotfix 揪出 3 個金流漏洞:確認堂卡訂單後沒啟動報名(D1)、取消/駁回堂卡訂單沒連帶取消報名(D2)、單筆取消繞過群組訂單(D3)。Mutation-test 3/3 RED 確認所有 guard 有效。因 context compaction 導致 6/8 工作流步驟違規→建立 hook-based 強制層(dispatch-guard / commit-gate / session-context / stop-gate)。
