整期報名精靈已完成
學員進入課程頁 → 點「整期報名」→ 精靈引導選課、班長意願、結算繳費 → 堂卡不足可加購 → 完成
驗收方式
  • 學員登入 → 課程群組頁 → 點「整期報名」按鈕
  • 選課步驟：勾選要報的課程 → 下一步
  • 結算步驟：看到每堂課的費用計算（堂卡/現金/免費依課程設定）

繳費期限（逾期自動取消）已完成
幹部可設定「報名後 N 天內要繳費」，逾期未繳費的報名自動取消，名額釋放給候補者
驗收方式
  • 幹部 → 檔期設定 → 輸入「繳費期限（天）」
  • 學員報名後 →「繳費紀錄」顯示「繳費期限：MM/DD HH:mm」
  • 精靈完成頁 → 顯示「請於 MM/DD 前完成匯款，逾期自動取消」
  • 逾期 → 自動取消報名 + 訂單取消 + 候補遞補
  • 已匯款（即使逾期）→ 不會被取消（已表達繳費意願）
  • 不設期限（留空）→ 不會自動取消（向下相容）

🖥️ 如何在測試網站驗收已完成的功能

  1. 開啟測試網站：http://[::1]:3000（需要先在本地啟動 dev server）
  2. 學員帳號：e2e-member@mediatek.com / 密碼 mediatek
  3. 幹部帳號：e2e-admin@mediatek.com / 密碼 mediatek
